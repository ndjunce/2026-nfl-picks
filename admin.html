Publish

To publish (only you can do this):
1. Click Download picks.js (or Copy) and replace the picks.js in your 2026-nfl-picks folder.
2. In that folder run:
  git add picks.js
  git commit -m "Week N picks"
  git push
3. Live site updates in ~1 min. The commit is your timestamped receipt.
Your in-progress entry auto-saves in THIS browser (localStorage) so you won't lose it mid-call. It is NOT published until you push.
