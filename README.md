# NFL Picks Tracker

A **static** website (instant load, no server, no cold-start) that shows the group's weekly
NFL picks + a live leaderboard. Friends open the link on their phones — no login, VIEW ONLY.
Live scores come from ESPN's free public scoreboard, polled in the browser every 30s.

- **`index.html`** — the public site everyone views (never edit).
- **`admin.html`** — YOUR private entry grid (click picks, generate `picks.js`).
- **`picks.js`** — the data file. Generated by admin.html; published by you via git push.

Players (fixed): **Nick, Clyde, Chet, Henry, Riley, Bobby**.
Live: https://ndjunce.github.io/2026-nfl-picks/  ·  Admin: add `/admin.html` to that URL.

## 🔒 Security model (why friends can only VIEW)
This is a **static** site — there is no server, and nothing a browser does can write to the repo.
- **Friends** open `index.html`: they see picks + live scores. If they open `admin.html` and click,
  it only changes THEIR OWN browser — they **cannot publish** (no repo access).
- **Only you** change what everyone sees, by committing & pushing `picks.js` (needs your GitHub login).
- **Edit history (receipt):** every push is a timestamped git commit, AND each generated `picks.js`
  stamps an `_editLog` line — a double record of what was entered and when.

The admin grid does NOT auto-save to the cloud on purpose: an instant-save would require a secret
write-token in the public page, which a friend could read. The git-push flow is what guarantees only
you can publish.

## ⏱ Weekly workflow (on your call — no file editing, no syntax)
1. Open **`admin.html`** (locally, or at `https://ndjunce.github.io/2026-nfl-picks/admin.html`).
   It auto-loads the current week's games from ESPN (or set Week/Season and click "Load").
2. **Click** each player's winner in the grid. **Type** each player's tiebreaker total (last game).
   Your entry auto-saves in your browser as you go (so you won't lose it mid-call).
3. Click **Generate picks.js** → **Download picks.js** (or Copy).
4. Replace `picks.js` in your local `2026-nfl-picks` folder, then:
   ```
   git add picks.js
   git commit -m "Week N picks"
   git push
   ```
5. Live site updates in ~1 minute. The commit is your timestamped receipt.

(Blanks are allowed — an un-clicked game just scores as a no-pick for that player.)

Future weeks are just the workflow above.

## Why static (not Render like last year)
Render free tier spins down → 30-60s cold-start. This is pure static files on a CDN → instant load,
no server to wake. The live scores run in each visitor's browser calling ESPN directly, so there's no
backend to host, sleep, or pay for.

## Notes / limits
- Live scores: ESPN public feed `site.api.espn.com/.../nfl/scoreboard` (free, no key). If it blips, the
  page keeps showing picks and fills scores in on the next 30s refresh (never blanks/crashes).
- Leaderboard counts a win only when a game is FINAL and ESPN marks a winner.
- Ties broken by closest tiebreaker (last game's total, once final).
- Everything is client-side; nothing to secure, no personal data.
